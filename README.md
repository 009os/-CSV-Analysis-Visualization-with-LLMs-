# BASIC-CSV-Analysis-Visualization-with-LLMs (College Assignment)

A simple tool for analyzing and visualizing CSV data using Large Language Models (LLMs).

## Features

- Upload and analyze CSV files
- Generate insights powered by LLMs
- Visualize data with charts and graphs
- No coding required

## Usage

1. Clone the repo:  
   `git clone https://github.com/009os/BASIC-CSV-Analysis-Visualization-with-LLMs.git`
2. Install dependencies:  
   `pip install -r requirements.txt`
3. Run the app:  
   `python app.py`
4. Upload your CSV and start exploring!

## Requirements

- Python 3.7+
- OpenAI API key (or compatible LLM provider)
